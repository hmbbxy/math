# 建立层次结构模型
把问题拆成三层：
 
- 目标层：要解决的最终目标

- 准则层：影响目标的各个评价指标

- 方案层：可供选择的各个方案

 总的来说，AHP的应用可以概括为：建结构 → 构矩阵 → 算权重 → 验一致。
# 构造两两比较判断矩阵
对同一层的元素两两对比重要程度，用1~9标度法打分，得到判断矩阵A。
a_{ij}：元素i相对元素j的重要程度；a_{ji}=1/a_{ij}。

# 计算权重向量
常用方法：算术平均法、几何平均法、特征值法（数模首选特征值法）。

```python

 import numpy as np

def ahp_eigenvalue_method(matrix):
    """特征值法计算AHP权重"""
    n = matrix.shape[0]
    
    # 1. 求矩阵的特征值和特征向量
    eig_vals, eig_vecs = np.linalg.eig(matrix)
    
    # 2. 找到最大特征值及其索引
    max_idx = np.argmax(eig_vals)
    lambda_max = np.real(eig_vals[max_idx])  # 取实部
    
    # 3. 提取最大特征值对应的特征向量
    weight_vec = np.real(eig_vecs[:, max_idx])
    
    # 4. 归一化（此时向量元素之和可能为负数或不为1，需要取其绝对值再归一化）
    weight_vec = weight_vec / np.sum(weight_vec)
    
    return lambda_max, weight_vec

# === 例子 ===
A = np.array([
    [1,   3,   5],
    [1/3, 1,   2],
    [1/5, 1/2, 1]
])

lambda_max, weights = ahp_eigenvalue_method(A)
print(f"最大特征值: {lambda_max:.4f}")
print(f"权重向量: {weights}")

# 计算CI和CR
n = A.shape[0]
CI = (lambda_max - n) / (n - 1)
RI_dict = {1: 0, 2: 0, 3: 0.58, 4: 0.90, 5: 1.12}
RI = RI_dict.get(n, 1.49)
CR = CI / RI if RI != 0 else 0
print(f"CI = {CI:.4f}, CR = {CR:.4f} {'✅ 通过' if CR < 0.1 else '❌ 未通过'}")
```

求出矩阵最大特征值\lambda_{max}对应的特征向量，归一化，得到各指标权重。

把判断矩阵输入代码，会算出一组特征值，挑里面数值最大的那一个，就是最大特征值\boldsymbol{\lambda_{max}}；
和它配对的那个向量，就是对应的特征向量。

+ 准则层权重怎么算？
构建判断矩阵：针对准则层（如质量、成本、效率），让专家进行两两比较，构造出n×n的判断矩阵A。

计算权重向量：使用上述方根法或和积法，计算矩阵A的最大特征值对应的特征向量（归一化后即为权重）。

一致性检验：计算CR值，若 CR < 0.1，则认为权重分配合理。

如果需要更精确的权重，推荐使用特征值法（调用 scipy.linalg.eig 计算最大特征值对应的特征向量），它在数学上更严谨。

# 一致性检验（必不可少！）
 
- 计算一致性指标：CI=\dfrac{\lambda_{max}-n}{n-1}，n是矩阵阶数

- 查表得到随机一致性指标RI

总的来说，AHP的应用可以概括为：建结构 → 构矩阵 → 算权重 → 验一致。你可以先尝试运行代码示例，再根据具体问题调整判断矩阵。

# 调整方案
+ 当 CR ≥ 0.1 时，说明判断矩阵逻辑不一致，需要调整。

调整策略：重点关注偏离一致性的元素。一个实用的方法是，检查矩阵中满足 `a_ij(i比j重要多少倍) ≈ a_ik * a_kj` 关系的元素，对偏差较大的 `a_ij` 进行修正。

修正公式：可计算期望值 `γ_ij = (a_ik * a_kj)` 的几何平均，用 `γ_ij` 替换原 `a_ij` 来逐步提高一致性。

+ 一致性检验没通过，不是去生搬硬套公式，而是找出那个“3×3=9但你填了5”的数字，把它改成7或8，或者去改旁边的数字来配合它。

# 归一化

+ 目的是让权重向量各元素之和为1。将上一步得到的n个方根值分别除以它们的总和即可

1. 按行（几何平均法/方根法）：第一步是把判断矩阵每一行的元素相乘再开n次方，得到 n 个数值。这代表每个指标（准则/方案）在所有指标中的综合大小。此时按行求出的值，再除以它们的总和，就是权重。
> 几何平均:在AHP中，它用于从判断矩阵中计算权重。具体是把判断矩阵每一行的所有元素相乘，再开n次方根。

3. 按列（和积法）：是先将每一列的元素除以该列的总和（这叫列归一化），然后再按行求和。目的是先消除量纲和比例影响，再综合。

+ 区别：按行求权重（方根法）是用乘积衡量整体，按列归一化（和积法）是用占比一步步汇总。两者殊途同归，方根法在Python里用 `np.prod` 更直观，和积法用 `sum` 更直观。

# 绘图
`nx.DiGraph()`：创建有向图，因为AHP的层次是从上到下的单向关系。

`G.add_node(name, layer=x)`：添加节点，并赋予节点属性 layer（层数，0=目标，1=准则，2=方案）。

`G.add_edge(parent, child)`：添加从父节点到子节点的连线。

`nx.multipartite_layout(G, subset_key='layer')`：多层布局函数。根据你赋予的 layer 属性，自动把不同层的节点摆成横向一排排的布局，非常适合AHP。

`nx.draw(...)`：用来画出节点和边，参数里可以配置颜色、大小、字体。

+ 逻辑清晰、学术严谨,同层同色,高对比度,色盲友好,兼容黑白打印
+ 在数模论文里，“文不如表，表不如图”。写完一段文字，如果你觉得“这段文字太长了，评委可能没耐心看”，那就果断把它变成一张图！

2. 只扰动准则层权重：比如把质量权重从0.1逐步调到0.7，每次调整后剩余权重按原比例分给成本和效率；

## 经验总结：
1. `if RI ！=0 else 0`是什么意思
+ 作用是防止程序除零报错。当矩阵阶数 n=1 或 n=2 时，RI 字典里对应的是 0，此时由于矩阵完全一致（CI也等于0），直接规定 CR=0 即可，不需要做除法。代码里是为了防御性编程，**避免报错**。
2. 最大特征值的作用
+ 求权重,一致性检验
3. 计算权重的这么多方法里，要怎么选择最适合的
+ 写「方根法」或「特征值法」其中一种即可，但在模型检验部分可以提一下**另一种方法得到的结果相近**，以此**证明稳健性**。
